Repositorio :
Un repositorio es el lugar donde se almacena y organiza el código de un proyecto junto con su historial de cambios. 
Esto permite mantener todos los archivos relacionados en un solo sitio y facilita el trabajo colaborativo, ya que varias
 personas pueden acceder y modificar el proyecto de manera ordenada.
Commit :
Un commit es un registro de cambios realizados en el proyecto. Se utiliza para guardar avances de forma segura y mantener un 
historial detallado
 de las modificaciones hechas. Gracias a esto, es posible identificar errores, recuperar versiones anteriores y entender 
la evolución del proyecto.

Push :
Push es el comando que envía los commits desde el repositorio local hacia un repositorio remoto. Su importancia radica 
en que permite compartir los cambios con otros integrantes del equipo, mantener una copia de respaldo en línea y sincronizar 
el trabajo realizado entre diferentes dispositivos o colaboradores.
